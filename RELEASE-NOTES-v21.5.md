# Budget Planner Beta v21.5 — Color Themes

- Added a small circular color-theme button to the Home header.
- Added four persistent whole-app themes: Blue, Purple, Light Pink, and Sage Green.
- Theme selection updates the main dashboard, forms, controls, cards, analytics accents, chart colors, modals, login surfaces, and action buttons.
- The selected theme is saved locally and restored when the app opens again.
- Updated the browser/PWA theme color to match the selected palette.
- Existing budgeting, income, expense, analytics, cloud, offline, import/export, and reporting behavior remains unchanged.
